# Сайт психолога Кристине Сафарянс

Одностраничный сайт психолога и сексолога: запросы, принципы работы, стоимость, ответы на вопросы и онлайн-запись.

**Посмотреть:** https://toctep-official.github.io/kristine-psy/

## Что внутри
- Онлайн-запись без сервера: анкета собирает сообщение, кнопка открывает WhatsApp, Telegram, MAX или iMessage с готовым текстом.
- Переливающиеся иконки мессенджеров и нижняя плашка «Записаться».
- Анимации на GSAP (ScrollTrigger, SplitText): «золотая нить» вокруг портрета и распутывающийся клубок.
- Светлая тёплая палитра: сливки, песок, персик, бордо и золото.

## Стек
HTML, CSS, JavaScript, GSAP. Один файл `index.html`, без сборки.
